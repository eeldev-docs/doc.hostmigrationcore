Changelog

1.1.3​

Added​

  • Debug overlay: shows role, epoch, state, host, successors, snapshots and lobby on screen. Turn it on with Show Debug Overlay, Set Debug Overlay Visible or the console variable HostMigration.Debug.Overlay, and pick the screen corner with Debug Overlay Corner. See Testing.
  • Move Party To Host: the host sends every client to another host, then follows them. See the Blueprint Overview.
  • On Host Connection Lost: fires on a host that seems to have lost its own connection. See Lost connection.
  • C++ adapters: new optional overrides IsOnline() and GetDebugInfo(). See Custom adapter.

Changed​

  • Choosing between hosts: the highest epoch now wins, then the most players. Before, the most players won first. A host that went offline can no longer win on its old player count. This applies to split-brain handling, Find Host In Lobby and lobby ownership.
  • Entering another lobby during a match now counts as leaving it: a host with players hands the match over first, and nothing from the old match is announced in the new lobby. If your players are in more than one lobby, for example a party lobby and a match lobby, call Set Steam Lobby or Set EOS Lobby with the match lobby's id. See Steam and EOS.
  • Steam and EOS: a player who drops out of the lobby during a match now joins it again automatically, not only during a migration.

Fixed​

  • EOS: the adapter now notices when the local player is no longer in the lobby.
  • EOS: a lobby is no longer joined again after the GameSession has moved to another lobby.
