Getting Started

Plugin Settings

Project Settings → Plugins → Host Migration, stored in DefaultGame.ini under [/Script/HostMigrationCore.HostMigrationSettings].

The most important ones:

SettingDefaultWhat it does
Hand Over On Window CloseonHost closing the window hands the match over first instead of counting as a crash.
Adapter ClassemptyThe online backend. Steam Adapter for Steam, EOS Adapter for EOS. Empty: picked from DefaultPlatformService (Steam, SteamCore, EOS, EOSCore), otherwise Null.
Client Wait MapnoneEmpty map clients wait in. Strongly recommended.
Snapshot Interval3 sHow often the host sends state. Lower = less lost progress, more traffic.
Connect Attempt Timeout30 sHow long one connection attempt may take before it is cancelled and retried. 0 = no limit.
Reconnect Grace Period30 sHow long the new host waits for previous players.
Inactive Player Timeout300 sHow long a player who left keeps their state for a rejoin.
Leaving Player PawnKeep In WorldWhat happens to the pawn of a player who leaves.
Keep Host URL OptionsonThe new host opens the map with the host's URL options (game mode settings), minus Skipped Host URL Options.
Wait For Game ReadyoffThe new host restores after Notify Game Ready, for games that set up the match after the map loads. See Games that set up the match later.
Restore Into Game PawnoffA returning player keeps the pawn the game spawns for them, with the saved pawn's state and position loaded into it.
Pause During Grace PeriodonPause while players reconnect.
Show Migration OverlayonShow a "reconnecting" screen during a migration.
Show Debug OverlayoffDraw the debug overlay on every machine.
Debug Overlay CornerTop RightScreen corner the debug overlay is drawn in: Top Left, Top Right, Bottom Left or Bottom Right.

Every setting has a tooltip in Project Settings → Plugins → Host Migration.
